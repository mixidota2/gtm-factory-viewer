# 需要地図の記事と出典を照合する

学童・保育・機械警備について、公表元の一覧と登録済みの原典を取得し、`index.html` に掲載した数字や出典と突き合わせます。この処理は記事を編集せず、公開もしません。

## 手元で実行する

Python 3 と、Poppler に含まれる `pdftotext` が必要です。リポジトリのルートで実行します。`--out` には、まだ存在しない出力先を指定してください。

```sh
python3 tools/demand/check_all.py --html index.html --out source-evidence
```

| 終了コード | 分かったこと |
| --- | --- |
| 0 | 今回の対象に限り、公式一覧・原典・保存済み記事が照合条件を満たしました。 |
| 3 | 資料を取得できなかった、資料やリンクが登録内容から変わった、照合結果が不足した、といった理由で確認が必要です。`result.json` と各グループの記録で理由を調べます。 |

学童・保育のPDFがすでに手元にある場合は、ファイルを明示して照合できます。登録されたものとハッシュが異なるPDFを、新しい原典として自動で採用することはありません。

```sh
python3 tools/demand/demand-integrated/verify.py --html index.html --gakudo-pdf /path/to/gakudo.pdf --nursery-pdf /path/to/nursery.pdf --out saved-source-evidence
```

## GitHub Actions で結果を読む

実行ページの要約を開くと、学童・保育と機械警備の結果が別々に表示されます。詳しくは `source-evidence` を開き、リンクがなければ同じ実行ページの成果物欄とログを確認します。

- **一覧・PDFを取得できない：** まず接続とHTTPの応答を確認します。取得できないだけでは、公表元で資料が変更されたとは言えません。
- **案内ページや公式一覧が変わった：** 何が変わり、どの候補PDFが未確認なのかを調べます。案内ページに変更があっても、登録済みの原典PDFは一致する場合があります。
- **取得したPDFが登録版と一致しない：** どの版を取得したかを確認し、対象期間、定義、記事に引用した表を読み比べます。数値が正しいか確認する前に、ハッシュだけを新しい値に置き換えません。

要約は検査で保存した結果を表示するだけです。元の終了コードや公開の判定は変えません。

## 保存するものと確認範囲

出典URL、取得結果、ハッシュ、対象の数値、照合結果を記録します。[manifest.json](manifest.json) に同梱の検証用ファイルの SHA-256 があり、原典URLと登録済みハッシュは各検証処理にも記載されています。

PDF全文はリポジトリに含めません。取得したPDF、一覧のHTML、PDFから抽出したページ本文はローカルでの確認に使い、公開CIの成果物には含めません。確認したのは各処理が対象にした一覧・資料・表です。他に新しい資料がないことや、記事のすべての解釈が正しいことまでは示しません。
