# ファーストフードの客数が増加。新店を含む協会調査

日本フードサービス協会の調査では、会員社のファーストフード店の延べ客数が2025年に前年比3.0%増えました。2026年1〜9月も、すべての月で前年の同じ月を上回りました。新店を含む会員社の集計で、既存店だけの増加や全国の飲食店全体の動きを示す数字ではありません。

## どの店の客数か

協会は毎月、会員社の本部に、新店を含む全店の実績を尋ねます。2026年9月にファーストフードとして集計されたのは52社・21,922店です。持ち帰りの店も含みます。

「客数」は重複を除いた人数ではありません。たとえば同じ人が繰り返し利用しても、別々の利用として数えます。そのため、利用する人が増えたのか、同じ人の利用が増えたのかは区別できません。集計対象は回答した会員社で、月ごとに同じ会社が回答するとは限りません。

## 客数はいつ、どれだけ増えたか

| 2025年 | 前年の同じ期間からの増加率 |
| --- | ---: |
| 年間 | 3.0% |
| 1〜3月 | 2.5% |
| 4〜6月 | 2.2% |
| 7〜9月 | 3.6% |
| 10〜12月 | 3.5% |

| 2026年 | 前年の同じ月を100%とした客数 |
| --- | ---: |
| 1月 | 105.6% |
| 2月 | 104.9% |
| 3月 | 103.3% |
| 4月 | 106.9% |
| 5月 | 106.1% |
| 6月 | 102.2% |
| 7月 | 103.9% |
| 8月 | 103.7% |
| 9月 | 103.4% |

たとえば2026年9月の103.4%は、前年9月より客数が3.4%多いという意味です。月によって元の客数が違うため、月ごとの比率をそのまま平均しても、期間全体の客数が何%増えたかは分かりません。

## 売上、客単価、店舗数はどう変わったか

| 指標 | 2025年（前年比） | 2026年9月（前年同月比） |
| --- | ---: | ---: |
| 売上 | +7.5% | +9.7% |
| 客数 | +3.0% | +3.4% |
| 客単価（客1人当たりの売上） | +4.4% | +6.1% |
| 店舗数 | +1.4% | +1.8% |

売上とともに客数と客単価が増えました。ただし、客単価が上がっても、値上げによるものか、客が買う品や個数が変わったためかは、この表では区別できません。客数の増加率から店舗数の増加率を引いても、既存店だけの客数の増加率にはなりません。既存店への客足を知るには、同じ店舗をそろえた比較が必要です。

2026年9月は前年より休日が1日多く、5連休がありました。協会は季節限定商品や販促にも触れていますが、各要因が客数を何人増減させたかは分かりません。ほかの業態から客が移ったか、全国市場全体が拡大したか、利益が増えたかも、この集計からは判断できません。また、前年比を何年分も掛け合わせても、2019年から同じ店舗を追跡した実測値にはなりません。
