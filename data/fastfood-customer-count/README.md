# 協会会員社のファーストフード全店で客数増。新店を含む結果

日本フードサービス協会の会員社では、新店を含むファーストフード全店の客数が2025年に前年比3.0%増え、2026年1〜9月も毎月前年同月を上回りました。既存店だけの増加や全国すべての飲食店の結果ではありません。

## 何を数えたか

数えたのは、協会会員社の新規店を含めた全店の利用客数です。異なる人の人数や一人当たりの来店頻度ではありません。全国の飲食店すべてを対象にした調査ではなく、月によって回答社が変わる可能性があります。2026年9月のファーストフードの集計対象は52社・21,922店です。

## 年間・四半期・月別の客数

2025年の年間客数は前年比3.0%増えました。四半期ごとも第1〜第4四半期の順に2.5%、2.2%、3.6%、3.5%増でした。2026年1〜9月の客数前年同月比は、順に105.6%、104.9%、103.3%、106.9%、106.1%、102.2%、103.9%、103.7%、103.4%です。月ごとの率を単純平均して、期間合計の増加率とはしません。

## 売上・客単価・店舗数との区別

2025年の売上は7.5%増、客単価は4.4%増、店舗数は1.4%増でした。2026年9月は売上9.7%増、客単価6.1%増、店舗数1.8%増、客数3.4%増です。客数にも増加があるため、値上げだけによる増収とは違います。ただし、新店を含むため既存店の成長率にはできません。客数の伸びから店舗数の伸びを引いて、既存店成長率とみなすこともしません。

## どこまで言えるか

確認できたのは、協会会員社のファーストフードで延べ利用客数が増えたことです。全国市場全体の拡大、個人の利用頻度、利益の増加は確認していません。2026年9月は前年より休日が1日多く、5連休や季節商品・販促の影響も報告されています。業態間で利用先が移った影響も切り分けられません。前年比の連乗を、2019年から同じ店舗を追った実測値には置き換えません。
