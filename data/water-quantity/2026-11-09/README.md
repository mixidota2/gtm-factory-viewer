# 水運売上と内航貨物の24か月比較

2024年8月〜2025年7月と2025年8月〜2026年7月の各12か月を比べます。対象は水運業全体の名目売上と、営業用内航貨物の重量・トンキロです。水運売上には外航・旅客・船舶貸渡等も含まれ、数量とは範囲が異なります。

- 売上：6,907,853 → 7,455,227百万円（+7.92%）。税込・名目。2026年6〜7月は速報。
- 内航貨物重量：296,482 → 298,097千トン（+0.54%）。
- 内航貨物トンキロ：149,309 → 149,258百万トンキロ（−0.03%）。数量は2026年7月月報に収録された月報値のみ。

`monthly.csv` は対象24か月の公表値です。列名に単位を示し、数量のXLS行番号、売上と数量それぞれの速報区分を付けています。原典URL・公表日・元ファイルのSHA-256・セル/ページ位置は `sources.json`、合計・増減率・確認範囲は `summary.json` を参照してください。原資料の全文は含めていません。

計算は「100 ×（当期12か月合計 ÷ 前年12か月合計 − 1）」です。月ごとの前年比の平均ではありません。年度合計行は使っていません。売上を数量で割って単価にしたり、増減率の差を価格寄与としたりすることはできません。

リポジトリのルートで `node tests/test_water_quantity.cjs` を実行すると、公開CSVの24月と合計・率、表示の範囲と速報注記を検査します。これは保存データの再計算であり、毎回原資料を取得して照合する処理ではありません。原典との照合範囲は `summary.json` に記載しています。

数値は公表単位で丸め済みです。「ほぼ横ばい」は数値変化が小さいという説明で、有意差検定ではありません。水運全体の数量と価格寄与は未確認です。
